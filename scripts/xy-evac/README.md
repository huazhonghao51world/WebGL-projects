# 应急疏散路线生成

当前路线（2026-11-25）按以下方法在页面内生成，校验全程穿墙格数为 0：

1. 切片：1F 地面以上 y=14.3 / 14.9 / 15.4 m 三个水平面，与所有可见网格（**含合批 InstancedMesh 实例**）求交，写入 0.25 m 占用栅格；门（MEN/PKM/JLM/zamen/Door）、地面、托盘等不计入。
2. 代价场：离墙 ≤1.5 m 代价按距离平方递增，<0.25 m 禁行，路线自动居中走通道。
3. 只在已知出口门洞（南侧卷帘门、北侧出口、北侧出口 2、库区东/东北/西门）半径 1.5 m 内放行穿墙。
4. A* 起点 → 集合点，再按“不触墙”视线简化折点，写入 `src/views/xy_factory/layers.js` 的 `evacuationCases`。

`slice-in-page.js` / `route-offline.cjs` 为旧版两层切片（不含实例）脚本，仅供参考；模型变更后应按上述方法重算。
