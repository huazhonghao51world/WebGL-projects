# 综合能源消费量与强度（GB/T 2589 演示口径）

## 综合消费量
各能源品种实物量 × 折标系数后求和，得综合能耗（tce）。  
本月累计演示值：**4120 tce**。

## 强度
- **单位产品能耗** = 综合消费量 / 主产品产量 → **1.28 tce/吨**
- **单位产值能耗** = 综合消费量 / 产值(万元) → **0.086 tce/万元**（同比 -3.2%）
- **单位增加值能耗** = 综合消费量 / 工业增加值(不变价，万元) → **0.142 tce/万元**

## 等价值 vs 当量值
- **当量值**：按燃料热值折标。
- **等价值**：电力等按火力发电煤耗等价值折标（演示可切换核对）。  
回答强度问题时必须声明当前口径。
