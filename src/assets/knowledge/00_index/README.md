# 灯塔2030 · 双碳能源问答资料库

> **性质**：演示示意数据，用于 VerifyLoop Demo 自然语言问答检索。  
> **厂区**：灯塔2030智能工厂（演示示意厂区）  
> **统计日**：演示「今日」快照；月度累计与右栏模块 KPI 对齐。  
> **硬约束**：场内光伏为辅电，≠外购购电；外购主通道止于厂内变电所。
