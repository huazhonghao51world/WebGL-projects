# 本机服务控制面板

双击 `start-panel.bat` → 浏览器打开 http://127.0.0.1:5099

- 显示本机局域网 IP、每个服务的运行状态、实际监听端口、PID，并给出可直接点开的地址（用局域网 IP，便于发给同事）。
- 每个服务可「启动 / 停止 / 重启 / 日志」，顶部可「全部启动 / 全部停止」。
- 在终端里手动启动的服务也能识别和停止（按命令行特征匹配进程树）；日志只记录由面板启动的服务（`logs/<id>.log`）。
- 面板只监听 127.0.0.1，局域网其他机器无法操作。

## 增删服务

编辑 `services.json`（保存后刷新页面即生效，无需重启面板）：

| 字段 | 说明 |
|---|---|
| `id` / `name` / `desc` | 标识与显示名 |
| `cwd` / `start` | 工作目录与启动命令 |
| `env` | 启动时附加的环境变量（两个 Vue 项目默认都用 3666，这里分别固定为 3666 / 3667） |
| `match` | 正则，匹配 node 进程命令行以识别该服务 |
| `ports` | 期望端口与说明（未监听时虚线显示） |
| `links` | 快捷链接 `{ label, port, path }` |
| `noStart` | 只允许停止（如已停用的旧服务） |
