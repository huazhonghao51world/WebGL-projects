新耀工厂数字孪生 · 国产化一体机现场运维手册

适用：银河麒麟 V10 / 统信 UOS（x86_64 海光、兆芯；aarch64 飞腾、鲲鹏）· 写给第一次接触 Linux 的同事 · 所有命令都可以点右上角「复制」

遇到问题先看 第 14 节「突发情况处理大全」，按症状找答案；解决不了就做 第 15 节「体检报告」 发给开发。

0. 这套系统是什么

一台国产化电脑上同时运行着整套数字孪生产品，不依赖外网、不依赖其他服务器：

新耀工厂大屏（灯塔交付端）
端口 3716 · 现场人员看的大屏
→
TwinStudio 平台
API 5184 · 案例、模型、发布版本、交付码、AI小新
→
数据（data 目录）
数据库 + 全部模型贴图，约 3.4 GB
TwinStudio 编辑器 5186
案例中心 / 资产库 / Agent 管理
API 联调台 5188
平台演示站 5185
视频网关 8889 / 8888
监控摄像头 → 网页视频
服务控制面板 5099
一键启停、看状态（仅本机）

程序更新走 GitHub：开发人员在公司修好 BUG、打包推送后，现场只需执行一条命令（或双击一个图标）就能更新；更新前自动备份数据，更新失败自动退回旧版本。

数据（约 3.4 GB）不走 GitHub，首次部署时用向日葵把数据包传到一体机桌面；之后数据一直保存在一体机上，更新程序不会动数据。

1. 每天怎么用（最常用）

部署目录（默认 /opt/xy-twin，以实际为准）里有一排带数字的图标，双击 → 选择「在终端中运行」即可：

图标作用什么时候用
1-一键安装启动.sh第一次运行自动安装；之后启动全部服务，并全屏打开大屏开机后大屏没出来 / 停过服务后
2-停止全部服务.sh停止所有服务关机前（可不做）、维护时
3-检查并更新版本.sh从 GitHub 拉取最新版本，自动备份 → 替换 → 自检开发通知「已发布新版本」时
4-打开大屏.sh全屏打开新耀工厂大屏（Alt+F4 退出）大屏窗口被关掉了
5-打开大屏-低显存模式.sh以低显存模式打开（贴图降到 512、关抗锯齿、减少阴影）大屏卡死、花屏、黑屏
6-服务控制面板.sh打开网页版控制面板（看状态、单独重启某个服务、看日志）想看哪个服务挂了
7-生成体检报告.sh收集系统、显卡、服务、日志信息生成报告出问题需要找开发时
双击 .sh 文件时，如果系统直接用文本编辑器打开了它：右键 → 「属性」→「权限」勾选「允许作为程序执行」；或者在文件管理器「设置」里把「可执行文本文件」改成「询问」/「运行」。也可以直接用第 2 节的终端方式。

开机后服务会自动启动（已注册为系统服务 xy-twin），一般只需要打开大屏即可。

2. 怎么打开终端

  1. 在部署目录空白处右键 → 「在终端中打开」（麒麟：「打开终端」），终端会自动进入当前目录。
  2. 或者按 Ctrl+Alt+T 打开终端，再输入（目录以实际为准）：
    cd /opt/xy-twin
  3. 输入命令后按 回车。需要管理员密码时会提示 [sudo] password，输入开机密码（输入时屏幕上不显示，输完直接回车）。
终端里复制是 Ctrl+Shift+C，粘贴是 Ctrl+Shift+V（不是 Ctrl+V）。正在运行的命令按 Ctrl+C 中断。

本手册里所有命令都形如 bash xy.sh 动作，必须在部署目录里执行。输入 bash xy.sh 不带参数会列出全部用法。

3. 首次部署（只做一次）

3.1 准备

项目要求
系统银河麒麟 V10 SP1 及以上 / 统信 UOS 20 及以上，x86_64 或 aarch64（终端输入 uname -m 查看）
磁盘部署目录所在磁盘可用空间 ≥ 20 GB（程序 0.3 GB + 数据 3.4 GB + 备份 7 份）
内存≥ 8 GB，推荐 16 GB
显卡已安装厂商显卡驱动（见 第 11 节）
浏览器Chromium 内核：Chrome / Chromium / Edge / 奇安信 / 360 等（Firefox 不推荐）
网络首次部署和每次更新时能访问 github.com；平时可离线运行
数据包开发通过向日葵传到一体机桌面的文件夹 xy-data-日期（约 1.7 GB）
令牌GitHub 只读令牌（以 github_pat_ 开头）。没有的话先按 第 4.1 节 生成

3.2 安装系统工具（一次）

# 麒麟 / UOS（apt 系）
sudo apt update
sudo apt install -y git curl xz-utils iproute2 mesa-utils
提示「无法定位软件包」时可跳过 mesa-utils（只用于查看显卡信息）。麒麟个别版本用 yum：sudo yum install -y git curl xz iproute。

3.3 下载程序

# 把 <令牌> 换成第 4.1 节生成的令牌（整段复制后再改，尖括号也删掉）
sudo mkdir -p /opt/xy-twin && sudo chown $USER:$USER /opt/xy-twin
git clone -b deploy-kylin --single-branch https://x-access-token:<令牌>@github.com/huazhonghao51world/WebGL-projects.git /opt/xy-twin
cd /opt/xy-twin

看到 Receiving objects: 100% 即下载完成（约 300 MB，视网速 1–10 分钟）。

3.4 导入数据

数据包文件夹 xy-data-日期（约 1.7 GB）由开发通过向日葵传到一体机桌面。传完后在终端执行（不用写路径，会自动在桌面找最新的数据包）：

cd /opt/xy-twin
bash xy.sh import-data

会依次显示：找到桌面上的数据包 → 校验 → 解压 → 数据库完整性： ok → 数据导入完成，然后自动启动服务。

「数据包校验失败」= 文件没传完整。删掉桌面上的该文件夹，让开发重新传，不要强行继续。导入成功后桌面上的数据包可以删除。

3.5 安装（开机自启 + 防火墙）

bash xy.sh install

会提示输入一次开机密码（用于注册开机自启 xy-twin.service 和放行防火墙端口）。最后打印「服务状态」全部为 运行中，并给出访问地址：

访问地址（机器换 IP 后用新 IP 访问即可，无需改配置）：
  新耀工厂大屏        http://192.168.1.20:3716/#/xy-factory
  TwinStudio 编辑器   http://192.168.1.20:5186
  ...
第一次启动平台要读取全部数据，可能需要 1–3 分钟，期间会显示「…仍在等待 平台 API 启动（首次较慢）」，属正常现象。

3.6 打开大屏，检查

  1. 双击 4-打开大屏.sh（或执行 bash xy.sh browser）。
  2. 先出现新耀 Logo 加载屏，进度到 100% 后进入大屏：
  3. 右上角 FPS 稳定在两位数即正常。若加载中卡死 / 花屏，见 第 10 节 的低显存模式。
  4. 在局域网其他电脑上用 http://一体机IP:3716/#/xy-factory 也能访问。

4. GitHub 访问令牌

程序仓库是私有的，一体机下载和更新程序需要一个只读访问令牌（一串以 github_pat_ 开头的字符）。令牌由仓库所有者账号 huazhonghao51world 在 GitHub 网页上生成，一般由开发人员生成后交给现场；现场也可以按下面步骤自己生成（需要该账号的登录权限）。

4.1 生成令牌（约 2 分钟，在任意能上网的电脑上操作）

  1. 浏览器登录 GitHub（账号 huazhonghao51world），打开：
    https://github.com/settings/personal-access-tokens/new
    也可以点右上角头像 → Settings → 左侧最下方 Developer settings → Personal access tokens → Fine-grained tokens → 右上角 Generate new token。
  2. 按下表填写（没提到的保持默认）：
    页面上的字段填写
    Token name（名称）xy-kylin-readonly（自己认得出即可）
    Resource owner（所属）huazhonghao51world
    Expiration（有效期）选 Custom，日期选一年后（到期前需要重新生成，见 4.3）
    Repository access（可访问的仓库）选 Only select repositories，在下拉框里只勾 WebGL-projects
    Permissions → Repository permissions点开后找到 Contents，选 Read-only（只改这一项；Metadata 会自动变成 Read-only）
  3. 拉到页面最下方，点绿色按钮 Generate token（如提示输入密码或验证码，按提示完成）。
  4. 页面上方显示一串 github_pat_… 字符，点旁边的复制图标。它只显示这一次，关掉页面后再也看不到，请立刻保存（建议存入密码管理器，或交给项目负责人保管）。
如果 Resource owner 下拉框里没有 huazhonghao51world，说明登录的不是仓库所有者账号；仓库若在组织名下，Resource owner 选该组织，并可能需要组织管理员在 GitHub 上批准后令牌才生效。

4.2 使用令牌

情况操作
首次部署把 3.3 节命令里的 <令牌> 整段替换掉（尖括号也删掉），例如：
git clone -b deploy-kylin --single-branch https://x-access-token:github_pat_11ABCDEF…xyz@github.com/huazhonghao51world/WebGL-projects.git /opt/xy-twin
令牌会自动保存在一体机上，之后更新不用再输入。
令牌过期 / 被删除（更新时提示「无法获取更新」，浏览器却能打开 github.com）按 4.1 生成新令牌，然后在部署目录执行：
bash xy.sh set-token github_pat_新令牌
显示「令牌已更新，可以访问 GitHub」即可

4.3 到期、泄露与作废

  • 查看到期时间：GitHub → Settings → Developer settings → Fine-grained tokens，列表里每个令牌都显示 Expires on（到期日）。到期前 7 天 GitHub 会给账号邮箱发提醒。
  • 续期：令牌不能延长，到期前按 4.1 生成新的，再执行 bash xy.sh set-token 替换即可，现场服务不受影响。
  • 作废（怀疑泄露、人员变动）：在上面的列表里点该令牌 → 页面最下方 Delete，立即失效。随后生成新令牌并在一体机上 set-token。
  • 多台一体机：可以共用一个令牌，也可以每台一个（名称写上机器位置，方便单独作废）。
令牌等同于钥匙：不要拍照发群、不要写在桌面便签或文档里。令牌只有「只读」权限，即使泄露也不能修改代码、看不到其他仓库，但仍请发现后立即作废并重新生成。

5. 启动 / 停止 / 重启

命令作用
bash xy.sh status查看每个服务是否运行、访问地址，并做健康检查
bash xy.sh start启动全部（已运行的跳过）
bash xy.sh stop停止全部
bash xy.sh restart重启全部（改了配置后执行）
bash xy.sh restart dengta只重启大屏站点

bash xy.sh restart studio只重启编辑器 / 联调台 / 演示站
bash xy.sh restart video只重启视频网关

系统服务方式（与上面等价，开机自启就是它）：

sudo systemctl status xy-twin     # 查看

sudo systemctl disable xy-twin    # 取消开机自启（enable 恢复）

6. 服务控制面板（5099）

双击 6-服务控制面板.sh，或在一体机浏览器打开 http://127.0.0.1:5099。

  • ● 运行中 绿色：正常；● 启动中：稍等几秒刷新；灰色「已停止」：点「启动」。
  • 端口框为虚线表示该端口没在监听（服务没起来）。
  • 「日志」按钮查看该服务最近 300 行日志。
  • 面板默认只允许本机访问。如需局域网其他电脑打开：local/xy.env 中加 PANEL_HOST=0.0.0.0 后 bash xy.sh restart panel（仅限可信内网）。

7. 更新版本（修 BUG）

开发人员修好 BUG 发布后，会通知「已发布新版本」。现场操作：

  1. 双击 3-检查并更新版本.sh（或终端执行 bash xy.sh upgrade）。
  2. 屏幕列出新版本及更新内容，例如：
    当前版本：2026.11.27-1136 · 大屏 175655e · 平台 772f243 · web-sdk 0.7.7
有 1 个新版本：
  11-28 10:20  2026.11.28-1020 修复注塑车间疏散路线
确认更新？更新期间大屏约中断 1 分钟 [y/N]
    输入 y 回车。
  3. 自动执行四步：备份数据（不停机）→ 停止服务 → 替换程序 → 启动并自检。
  4. 看到绿色「更新成功」即完成；大屏页面按 F5 刷新（全屏模式先 Alt+F4 再双击「4-打开大屏」）。
自检失败时脚本会自动退回旧版本并提示「已回退」，现场照常使用，然后按第 15 节生成体检报告发给开发。

其他用法：

命令说明
bash xy.sh check只检查有没有新版本，不更新
bash xy.sh upgrade --yes不询问直接更新（远程协助时用）
bash xy.sh upgrade desktop离线更新：一体机不能访问 GitHub 时，开发用向日葵把更新包 xy-kylin-日期.bundle 传到一体机桌面，再执行此命令（自动使用桌面上最新的更新包）
bash xy.sh version查看当前版本号
更新只替换程序，不会动：data/（数据）、local/（现场配置：交付码、摄像头、密码、端口）、backups/、logs/。不要手动修改 app/ 目录里的文件，更新时会被覆盖。

8. 回退到旧版本

新版本有问题（例如某个功能不对），可立即退回，数据不受影响：

bash xy.sh rollback          # 退回到更新前的版本
bash xy.sh versions          # 列出本机可回退的版本（版本号 + 时间 + 说明）
bash xy.sh rollback a1b2c3d  # 退回到指定版本号
回退后，下次执行「检查并更新」仍会提示有新版本。等开发修复并发布更高版本后再更新即可。

9. 数据备份与恢复

数据目录 data/ 包含：数据库 platform.sqlite（案例、资产、发布版本、交付码、AI小新会话与模型配置）、objects/（全部模型、贴图、配置包）、vtk-cache/（仿真缓存）、delivery-codes.json（交付码）。

命令说明
bash xy.sh backup在线热备份到 backups/data-时间，不用停服务；自动校验数据库行数与完整性。自动保留最近 7 份
bash xy.sh backup ~/桌面/xy-backup备份到桌面，再用向日葵把该文件夹传回开发电脑留存
bash xy.sh restore backups/data-20261128-1020恢复到某份备份（当前数据改名保留为 data.before-restore-时间，不会丢）
bash xy.sh import-data <数据包目录>用开发传到桌面的新数据包整体替换（例如公司那边新发布了案例）。不写目录时自动找桌面
每次「更新版本」前都会自动备份一次（目录名 data-before-upgrade-时间）。重要操作（如在编辑器里大改案例）前建议手动备份。
不要直接删除或复制正在运行的 data/platform.sqlite，会导致数据损坏。备份一律用 bash xy.sh backup。

10. 地址参数（显存降档等）

大屏地址可以带参数，用来降档、排查问题。参数写在 # 前面的 ? 后面，多个参数用 & 连接：

http://一体机IP:3716/?参数1=值&参数2=值#/xy-factory
# 例：低显存模式
http://127.0.0.1:3716/?gpu=compact#/xy-factory
# 也可以写在路由后面（效果相同）
http://127.0.0.1:3716/#/xy-factory?gpu=compact

用脚本打开（自动全屏）：bash xy.sh browser "gpu=compact"，多个参数：bash xy.sh browser "gpu=compact&lite=1"。

10.1 日常可用参数

参数作用什么时候用
gpu=compact低显存模式：贴图最长边 512（默认 1024）、关闭抗锯齿、像素比 ≤ 1、阴影贴图缩小且只保留 1 盏主光 + 2 盏聚光灯投影、POI 图标走 CPU 生成加载卡死、花屏、黑屏、马赛克、帧率个位数
lite=1关闭页面 UI 动效（面板动画、数字滚动）CPU 较弱、界面操作不跟手
系统不会自动降档：是否使用低显存模式完全由地址参数决定。确认需要降档后，用「5-打开大屏-低显存模式.sh」打开即可；如需固定为默认，联系开发修改桌面图标。

10.2 排查参数（开发远程指导时用）

参数作用
gldebug=1在浏览器控制台（F12）打印 WebGL / 显卡诊断信息，并开放调试入口
bare=1只显示 SDK 加载的原始场景，不执行任何业务（POI、产线、面板逻辑、配置包都不运行）
bare=1&step=1 … step=4在 bare 基础上逐级加回：1 场景配置包；2 + POI 与点选；3 + 产线动画；4 + 渲染调优（阴影等）。用来定位哪一层导致卡顿
noprofile=1完整业务照常，只是不应用场景配置包（灯光、材质保持原始）
only=lighting,l-building场景配置包只执行列出的模块
strip=shader / strip=all去掉配置包的部分效果：env 环境贴图、envmap 反射、fog 雾、spot 聚光灯、shadow 阴影、shader 自定义着色器、extra 额外网格；all = 全部
noenv=1拦截天空背景与环境贴图
hide=xy-shinei,xy-vfx隐藏整个模型实体（xy-campus-exterior / xy-campus-core / xy-shinei / xy-prop-sq3 / xy-mesh / xy-vfx）
perf=all / perf=prewarm,softShadow关闭交付端额外渲染负担（prewarm 预编译、shadowOverride 大阴影、indoorShadow 室内投影、shadowRefresh、raycastWarm、softShadow）；on=… 重新打开
xyDeliveryCode=TWN-…临时换用另一个交付码（不改配置文件）
排查参数只影响当前打开的这一个页面，关掉页面就恢复，不会改动任何配置或数据。

11. 浏览器与显卡

11.1 推荐浏览器

Chromium 内核（Chrome / Chromium / Edge / 奇安信可信浏览器 / 360 安全浏览器）。bash xy.sh browser 会自动找到已安装的浏览器，并带上以下启动参数：

启动参数作用
--ignore-gpu-blocklist关键：国产显卡常被 Chromium 列入 GPU 黑名单，不加会退回 CPU 软件渲染，帧率只有 1–3
--kiosk无边框全屏（Alt+F4 退出）
--enable-gpu-rasterization页面绘制也走 GPU

如果是手动打开浏览器，可在浏览器地址栏打开 chrome://gpu 检查：「WebGL」和「WebGL2」应为 Hardware accelerated；若显示 Software only，说明没用上显卡（驱动问题或被黑名单）。

11.2 显卡驱动

lspci | grep -iE "vga|3d|display"     # 看显卡型号
glxinfo -B | grep -iE "renderer|version"   # 看驱动：renderer 不能是 llvmpipe（软件渲染）
renderer 显示 llvmpipe / softpipe = 显卡驱动没装好，大屏会极卡。请安装显卡厂商（芯动、摩尔线程、景嘉微、兆芯、海光配套 AMD 等）提供的麒麟版驱动后重启。

11.3 已知显卡情况

显卡建议
芯动 风华三号（Fantasy III）默认模式可运行（约 15–30 FPS）；如加载时卡死用 gpu=compact
集成显卡 / 显存 ≤ 2 GB建议 gpu=compact
独立显卡显存 ≥ 4 GB默认模式

摄像头不通不影响大屏其他功能，只是监控画面黑屏。bash xy.sh logs video-gateway 查看原因（常见：IP 不通、密码错、摄像头离线）。

12.4 演示视频（没有真实摄像头 / 外网演示时）

系统自带 4 段开源工厂视频（冲压、包装、制浆、车间，Wikimedia Commons CC 授权），循环播放到 13 路监控画面，不需要任何摄像头：

bash xy.sh camera demo   # 切到演示视频

bash xy.sh camera        # 查看当前是哪种

默认就是演示视频（更新后自动生效）。接入真实摄像头后执行 camera live。切换后刷新大屏即可，设置会保留（重启、更新后不变）。素材署名见 app/video/videos/README.md，对外演示请保留。

13. 场景包替换（一般不涉及）

场景（模型、灯光材质配置包）保存在平台数据里。场景组出新版本时，推荐由开发在公司发布，再通过向日葵传到一体机桌面，二选一：

方式 A：整体数据包（推荐）

开发重新打数据包，用向日葵传到一体机桌面 → 现场 bash xy.sh import-data。原数据自动改名保留。

方式 B：场景包 + 编辑器导入

场景组配置包按 three.js r187 开发，SDK 也必须是 r187（web-sdk ≥ 0.7.1）。版本不一致会导致国产显卡卡死。方式 B 导入前请与开发确认配置包版本号（配置包 version 必须比当前高）。

出问题可以立即回到旧场景：编辑器「案例 → 发布记录」重新发布上一版本；或 bash xy.sh restore backups/… 恢复导入前的数据。

14. 突发情况处理大全

按症状找，从上往下试。每一步做完都刷新大屏看看是否恢复。

大屏打不开：浏览器显示「无法访问此网站」/「拒绝连接」
  1. bash xy.sh status，看哪些显示 未运行。
  2. bash xy.sh start 启动（已运行的会跳过）。
  3. 还不行：bash xy.sh restart。
  4. 还不行：bash xy.sh logs dengta 看最后几行；若提示 EADDRINUSE = 端口被占用，见下面「端口被占用」。
  5. 其他电脑访问不了、本机可以：防火墙没放行，执行 bash xy.sh install（会重新放行端口）；或确认两台电脑在同一网段（互相 ping 得通）。
大屏一直停在加载屏 / 进度不动
  1. 看加载屏上的阶段文字：停在「正在校验交付码」→ 平台没起来，bash xy.sh restart platform。
  2. 停在「正在下载 / 解析模型」超过 3 分钟 → 磁盘或内存紧张，free -h、df -h 查看；关闭其他程序后刷新。
  3. 停在「正在显示场景」→ 显卡压力过大，改用 5-打开大屏-低显存模式.sh。
  4. 首次加载约 20–60 秒属正常（之后有缓存）。
加载过程中电脑卡死 / 鼠标不动 / 花屏 / 马赛克 / 黑屏
  1. 等 30 秒；仍无响应按 Ctrl+Alt+F2 切到文字终端登录（或长按电源键重启）。
  2. 重启后用 5-打开大屏-低显存模式.sh 打开（gpu=compact）。
  3. 仍卡：检查显卡驱动（第 11.2 节），renderer 不能是 llvmpipe。
  4. 仍卡：用排查参数 bash xy.sh browser "gpu=compact&bare=1"，能打开说明是业务层，再试 step=1…step=4 定位，把结果告诉开发。
页面提示「WebGL 上下文丢失」或画面突然全黑

显存不足或显卡驱动重置。系统不会自动降档，请：F5 刷新一次；频繁出现就固定使用 低显存模式。同时关闭其他占用显卡的程序（视频播放器、其他浏览器标签页）。

帧率很低（FPS 个位数）、操作卡顿
  1. 浏览器打开 chrome://gpu：WebGL 若为 Software only → 浏览器没用上显卡，必须用 bash xy.sh browser 打开（带 --ignore-gpu-blocklist）。
  2. 加载完成后前几秒帧率低属正常（后台在准备），10 秒后仍低再处理。
  3. 用低显存模式；再加 lite=1 关闭界面动效。
  4. 大屏分辨率过高（4K）时，在显示设置里改为 1920×1080。
监控视频黑屏 / 播放不了
  1. bash xy.sh status 看 video-gateway 是否运行；未运行 → bash xy.sh restart video。
  2. 提示「未配置摄像头」→ 没有 local/xy-cameras.yml，按 12.3 配置；或先用 bash xy.sh camera demo 显示演示视频。
  3. bash xy.sh logs video-gateway：出现 connection refused / timeout = 摄像头 IP 不通；401 = 账号密码错。
  4. 局域网其他电脑看不了视频但本机可以：放行 UDP/TCP 8189（bash xy.sh install 会自动放行），不通时页面会自动改用 HLS（延迟稍高）。
编辑器（5186）登录不了 / 提示 Origin not allowed
  1. 密码是否被改过（看 local/xy.env 的 TWIN_ADMIN_PASSWORD）。
  2. 必须通过 http://IP:5186 访问，不要直接访问 5184。
  3. bash xy.sh restart studio platform。
更新失败：「无法获取更新」/「无法连接 GitHub」
  1. 浏览器能否打开 https://github.com ；不能 → 网络问题（代理、内网限制），联系网管；或让开发生成离线更新包，用向日葵传到桌面后执行 bash xy.sh upgrade desktop（第 7 节）。
  2. 能打开 → 令牌过期，bash xy.sh set-token 新令牌（第 4 节）。
  3. 提示 Your local changes would be overwritten 等 → 有人改了 app/ 下的文件，更新会强制恢复，直接重试 bash xy.sh upgrade。
更新后功能异常

bash xy.sh rollback 立即退回旧版本（数据不变），再通知开发。

端口被占用（日志里出现 EADDRINUSE / address already in use） 
sudo ss -ltnp | grep 3716     # 看谁占用了 3716（换成提示里的端口）
bash xy.sh stop; bash xy.sh start

若是其他程序占用，可在 local/xy.env 改端口（如 PORT_DENGTA=3726）后 bash xy.sh restart，并告知使用人员新地址。

磁盘满了（No space left on device） 
df -h .                       # 看剩余空间
du -sh backups/* logs/*       # 看哪些占空间
ls -dt backups/data-* | tail -n +4 | xargs rm -rf   # 只保留最近 3 份备份
rm -f logs/*.log.old logs/doctor-*.txt

数据太大时可把数据目录迁到大磁盘：停服务 → mv data /data/xy-twin → local/xy.env 写 TWIN_DATA_DIR=/data/xy-twin → 启动。

一体机换了 IP / 搬到新网络

不需要改任何配置，用新 IP 访问即可（bash xy.sh status 会显示新地址）。所有站点通过同源代理访问平台，不绑定 IP。

停电 / 非正常关机后
  1. 开机后服务自动启动；bash xy.sh status 确认全部运行。
  2. 数据库使用 WAL 日志，异常断电一般不会损坏；如平台起不来且日志出现 database disk image is malformed，用最近备份恢复：bash xy.sh restore backups/最新的目录。
开机后服务没有自动启动 
sudo systemctl status xy-twin     # 看状态与报错
bash xy.sh install                # 重新注册开机自启
时间不对（页面时间、日志时间错误） 
timedatectl                                   # 查看
sudo timedatectl set-timezone Asia/Shanghai
sudo timedatectl set-time "2026-11-28 10:00:00"   # 无网络时手动设置
误删了文件 / 程序目录乱了 
git status                        # 看哪些程序文件被改或删
git reset --hard HEAD; bash xy.sh restart   # 恢复程序文件（不影响 data/ local/ backups/）
